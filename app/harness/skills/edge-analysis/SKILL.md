---
name: edge-analysis
description: Test whether a defined setup has positive expectancy across a reviewed sample.
triggers: edge, expectancy, win rate, sample, backtest, performance, consistency, statistics, history
---

Define setup variables before calculating results. Segment by instrument, session, regime,
context timeframe, trigger timeframe, news proximity, and execution grade. Report sample size,
win rate, average win/loss in R, expectancy, dispersion, and missing data. Do not declare an edge
from a small or selectively reviewed sample.
