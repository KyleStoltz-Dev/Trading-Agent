Review loop

  1. Record visible facts.
  2. Label context hypotheses.
  3. Define a lower-timeframe trigger.
  4. Predefine invalidation and risk.
  5. Review execution separately from outcome.

No autonomous order placement. Every moment is unique; the purpose is to measure repeatable decisions across regimes.
